Holistic Practices

Quality information about the practices themselves.

Holistic Tribe Lombok is not only a place to discover facilitators and events. It is also a non-profit initiative that wants to make holistic practices easier to understand. These guides are designed to be calm, clear and useful — so travelers, seekers and locals can explore with more awareness.
